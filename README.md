# 🌤️ Weather App Pro

A responsive, feature-rich Weather Application built with **Vanilla JavaScript**, **HTML5**, **CSS3**, and the **Open-Meteo API**.

## ✨ Features
- 🔍 **City Search:** Search weather conditions for any city worldwide.
- 📍 **Geolocation Support:** One-click fetch for live local weather based on user coordinates.
- 📅 **5-Day Forecast:** Displays daily high/low temperatures.
- 💨 **Detailed Metrics:** Shows current temperature, wind speed, and humidity.
- 📱 **Fully Responsive:** Clean UI designed for all device sizes.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, ES6+ JavaScript
- **API:** Open-Meteo Geocoding & Weather Forecast API
